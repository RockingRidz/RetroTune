# RETOR TUNE

## Introduction
Retor Tine is a custom handheld gaming and audio device built around a compact microcontroller board. It is designed to run retro games, play audio files from storage, and fit inside a portable, pocket-sized housing.

## Features
* Classic retro games including block stacking, snake, space shooter, and jumping mechanics.
* Real-time analog control via an integrated thumbstick for smooth directional movement and menu navigation.
* MicroSD card support to load games and stream audio files.
* Filtered headphone jack output for clean sound reproduction.
* Monochrome display screen for high-contrast visuals and retro user interfaces.

## 3D Design
* Pocket-sized, two-piece snap-fit outer shell that requires no exterior screws.
* Internal mounting chassis that holds the microcontroller, display, and modules securely in place.
* Custom thumbstick cap designed to fit the analog module comfortably.
* Integrated cutouts for the charging port, headphone jack, and screen window.

## Parts
* Microcontroller board
* Monochrome OLED display screen
* Dual-axis analog joystick module
* MicroSD card reader module
* 3.5mm audio jack
* Lithium battery and charging module
* 3D printer filament
